# Judgement Criteria

## Pass

Use when as-built evidence is complete and consistent.

## Conditional Pass

Use when minor correction is needed but handover may continue with conditions.

## Pending

Use when required as-built document or evidence is missing.

## Reject

Use when wrong site/scope, major document defect, or invalid handover evidence exists.

## Manual Check Required

Use when AI cannot safely judge as-built completeness.

## Common Rules

- Do not pass major site/scope mismatch.
- Do not pass missing mandatory handover evidence.
- Handover recommendation is advisory only.
