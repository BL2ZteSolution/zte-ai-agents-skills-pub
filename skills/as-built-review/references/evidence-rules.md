# Evidence Rules

## Acceptable Evidence

- As-built document or compact summary.
- Installed drawing/equipment evidence summary.
- Site/link/scope context.
- Supporting handover evidence if available.

## Weak Evidence

- Document without site/link identity.
- Partial installed evidence.
- Unclear drawing or equipment reference.

## Invalid Evidence

- Wrong site/scope.
- Invalid or incomplete as-built document.
- Missing installed evidence for required scope.

## Risk Flags

- `missing_as_built`
- `incomplete_as_built`
- `scope_mismatch`
- `site_mismatch`
- `missing_installed_evidence`
- `unclear_document`
- `manual_verification_required`
