# Review Scope

## In Scope

- Pathloss file/report evidence.
- Link identity consistency.
- Site A / Site B information.
- Frequency, band, path, or link planning context if present.
- Technical risk and missing planning evidence.

## Out of Scope

- Running Pathloss software.
- Final RF design calculation.
- Engineering approval.
- iEPMS/Firebase updates.
- Raw planning API/model integration.
