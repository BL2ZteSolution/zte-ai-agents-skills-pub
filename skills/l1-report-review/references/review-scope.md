# Review Scope

## In Scope

- L1 report completeness.
- Site identity consistency.
- Before-work photo evidence presence.
- After-work photo evidence presence.
- Required photo angle and quality readiness.
- Mandatory report fields if available.
- Report and site context alignment.
- Defects and missing evidence.

## Out of Scope

- Firebase or iEPMS updates.
- Workflow step routing or `next_step` decision.
- Replacement of L1 step skills.
- Customer acceptance claims.
- Raw OCR, image model, or TIPIC integration.
