# Judgement Criteria

## Pass

Use when L1 report and required before/after evidence are complete, consistent, and no blocking defect exists.

## Conditional Pass

Use when minor missing or unclear items do not block workflow and the follow-up action is explicit.

## Pending

Use when required report/photo evidence is missing.

## Reject

Use when wrong site, wrong report, major missing evidence, invalid report, or major quality issue exists.

## Manual Check Required

Use when evidence cannot be safely judged by AI.

## Common Rules

- Do not pass incomplete report/photo evidence.
- Wrong-site evidence must be Reject or Manual Check Required.
- Missing mandatory evidence must be Pending.
- Critical mismatch or compliance risk must not pass.
