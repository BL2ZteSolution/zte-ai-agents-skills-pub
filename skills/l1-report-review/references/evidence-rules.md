# Evidence Rules

## Acceptable Evidence

- L1 report file or compact report summary.
- Before-work photos or compact photo evidence summary.
- After-work photos or compact photo evidence summary.
- Site code/link ID in report or provided context.
- Submission screenshot or confirmation if available.

## Weak Evidence

- Report summary without site identity.
- Photo summary without before/after timing.
- Unclear photo evidence.
- Missing link between evidence and site.

## Invalid Evidence

- Wrong site or wrong link.
- Wrong report/template.
- Missing mandatory before/after evidence.
- Report content that contradicts site context.

## Risk Flags

- `missing_l1_report`
- `missing_before_photo`
- `missing_after_photo`
- `site_mismatch`
- `unclear_photo`
- `incomplete_report`
- `wrong_template`
- `manual_verification_required`
