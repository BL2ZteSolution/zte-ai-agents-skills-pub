# Review Scope

## In Scope

- EHS checklist/report completeness.
- Safety evidence readiness.
- PPE, hazard, and work condition evidence if present.
- Site identity consistency.
- Critical safety issue identification.

## Out of Scope

- Final permission to work.
- Firebase/iEPMS updates.
- Replacement of `step-ehs`.
- Raw image model, OCR, or backend API integration.
